\section{1. Executive Business Context \& Problem Framing}
Worker's Compensation insurance requires reserves to be set aside as soon as an injury is reported. Initial case estimates (\texttt{InitialCaseEstimate}) set by claims adjusters are often subjective and subject to severe revision over time as medical treatments progress.
\begin{itemize}
    \item \textbf{Business Objective:} Build an automated, data-driven ML pipeline to accurately predict final settlement cost (\texttt{UltimateIncurred\allowbreak{}ClaimCost}) early in the claim lifecycle.
    \item \textbf{Operational Impact:} Enable early triage of severe claims (Top 10\% highest cost) to assign experienced adjusters, optimize financial reserve allocation, and mitigate severe tail-risk losses.
\end{itemize}

\section{2. Dataset Architecture \& Leak-Proof Preprocessing}
The dataset comprises $100{,}000$ historical claim records combining demographic attributes (\texttt{Age}, \texttt{Gender}, \texttt{MaritalStatus}), financial status (\texttt{WeeklyPay}, \texttt{HoursWorkedPerWeek}, \texttt{DaysWorkedPerWeek}), family dependents (\texttt{DependentChildren}, \texttt{DependentsOther}), dates, and unstructured text (\texttt{ClaimDescription}).
\begin{itemize}
    \item \textbf{Feature Engineering:} Domain feature \texttt{ReportDelayDays} calculated strictly as $(\text{DateReported} - \text{DateTimeOfAccident}) / 86{,}400\text{ s}$ (converting seconds to days).
    \item \textbf{Strict Leak-Proof Protocol:} Split into 80\% Train ($80{,}000$ rows) and 20\% Test ($20{,}000$ rows) \emph{prior} to fitting transformers. Scikit-learn \texttt{Pipeline} and \texttt{ColumnTransformer} wrap \texttt{RobustScaler} for numerical features and \texttt{OneHotEncoder} for categorical features.
\end{itemize}

\section{3. Target Variable \& Evaluation Benchmark Metrics}
The target \path|UltimateIncurredClaimCost| exhibits a heavy-tailed, highly right-skewed distribution. Models are trained on $\log(1+y)$ with upper-bound prediction clipping at $\max(\log(1+y_{\text{train}}))$ to prevent exponential prediction explosions upon applying $\exp(\cdot)-1$.
\begin{itemize}
    \item \textbf{Primary Regression Metrics:} Root Mean Squared Error (RMSE \$), Mean Absolute Error (MAE \$), Mean Absolute Percentage Error (MAPE \%), and $R^2$ Score.
    \item \textbf{Secondary Triage Metrics:} ROC-AUC and Precision@Top-10\% for high-cost claim binary detection (threshold at 90th percentile, $\approx \$12{,}913.88$).
\end{itemize}

\section{5. Key Technical Findings \& Methodological Validation}
\begin{itemize}
    \item \textbf{20\% Error Reduction:} Non-linear tree ensembles (Random Forest, LightGBM) reduce MAE from $\$4{,}128.06$ down to $\mathbf{\$3{,}301.41}$, proving strong capability to capture complex tabular interactions.
    \item \textbf{Positive $R^2$ Variance Explained:} $R^2$ rises from negative values on linear baselines to $\mathbf{+0.2512}$ with Random Forest.
    \item \textbf{Severe Claims Triage:} Baseline achieves $\text{ROC-AUC} \approx 0.907$ for identifying Top 10\% claims, setting a solid classification benchmark.
\end{itemize}

\section{6. Project Roadmap \& Upcoming Milestones (Weeks 10--12)}
\begin{itemize}
    \item \textbf{Week 10 (NLP Integration):} Extract text features from \texttt{ClaimDescription} using TF-IDF n-grams and fine-tune a pre-trained Transformer (\texttt{DistilBERT}) to capture injury severity semantics.
    \item \textbf{Week 11 (Multimodal Fusion \& Optimization):} Combine tabular features with text embeddings into a unified LightGBM / Neural Architecture.
    \item \textbf{Week 12 (Interpretability \& Final Report):} Apply SHAP (SHapley Additive exPlanations) for global feature importance and local claim risk explanations.
\end{itemize}
