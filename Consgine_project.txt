The Project
Pick a problem and solve it.

How the project works
The goal is rigorous application. You'll work in groups of up to four, and the goal is to use the methods learned in class in a real setting.

🧵 Improve your data mining as it goes
Choose a dataset and frame a problem. Then, as each new method arrives: clustering & PCA (W7), neural networks (W8), CNNs (W9), transformers (W10) apply it to your own data if relevant. By the final week you'll have the tools to deal with all common types of data.

What a strong project looks like
Framing. Inputs, target, and evaluation metric defined before modeling.
Baseline always. Start with a naive baseline (majority class, predict-the-mean).
Broad. Compare several model families across the toolbox, including at least one advanced method (boosting and/or a neural approach).
Leak-proof. Test set untouched until the end; CV for tuning; pipelines for preprocessing.
Interpreted & honest. Explain why a model works (feature importance, SHAP, other method) and study the failure modes.

Timeline & deliverables
Week 6 Kickoff. Form your group, choose a dataset, frame the problem. Start EDA + a baseline with the tools you have.
Weeks 7-10 Deep learning methods. Implement the latest methods to your dataset if it fits the data.
Week 9 Proposal. One page with a dataset, a problem, evaluation metrics, and a baseline plan.
Weeks 11-12 Project help. Dedicated in-class time; examples using all the different methods.
End of Week 12 Report due. 6-8 pages: Problem → Data → Methods → Results → Interpretation → Limitations → Conclusion.
